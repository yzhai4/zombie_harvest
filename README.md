《尸潮农场》是一个生存、经营、建设与打僵尸网页游戏。

## 主要操作

- WASD / 方向键：移动
- E：交互、预览、目标锁定与确认
- B：背包
- C：建造模式
- F / 空格：攻击
- R：进食，食物同时作为营地每日口粮
- N：结束白天并进入尸潮
- Esc：关闭面板
- H：隐藏或恢复界面

# 尸潮农场

《尸潮农场》是一个生存、经营、建设与打僵尸网页游戏。

## 当前基线

- 来源：Sites 项目「尸潮农场」
- 当前生产版本：v76
- Sites 提交：`ea24e579ba5bfe32cacb8695a054d61da406e512`
- 入口：`dist/index.html`
- 站点：https://zombie-harvest.jimmy-vaughanowl.chatgpt.site/
- 访问级别：公开访问

## 主要操作

- WASD / 方向键：移动
- E：交互、预览、目标锁定与确认
- B：背包
- C：建造模式
- F / 空格：攻击
- R：进食，食物同时作为营地每日口粮
- N：结束白天并进入尸潮
- Esc：关闭面板
- H：隐藏或恢复界面

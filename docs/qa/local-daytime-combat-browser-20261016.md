## 实际步骤

1. 打开本地 dist，页面标题为“我是大救星 · 尸潮农场”。
2. 点击“开始新游戏”，DOM 显示第 1 天、06:05、生命 100、行动体力 78。
3. 点击“推进到下一次威胁”，DOM 进入“第 1 天 06:15 · 清晨 · 实时战况”。
4. DOM 可见实时威胁入口；检索到“当前剩余”战斗读数。
5. 关闭临时 tab 并停止 loopback server。

## 证据边界

这是真实 browser 的本地启动/昼间推进/威胁转换证据，证明当前 dist 能在浏览器中启动并进入实时战况。它不是完整三日、十四日自然回归，也没有把 DOM 出现“当前剩余”扩大为自动塔/NPC实际命中数值；数值守恒继续由 `check-daytime-combat.mjs` 11/11 项 inline runtime 合同覆盖。

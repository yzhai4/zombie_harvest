# 扩展内容验收表

新增内容合入前逐项勾选；未通过项目必须记录原因、降级方案和回滚点。武器、支线、NPC、科技、建筑、势力和据点均适用。

## 身份与接口

- [ ] 稳定 ID 唯一，未复用历史 ID。
- [ ] `contentVersion` 已填写，字段变更有迁移说明。
- [ ] 已登记到正确注册表：`WEAPON_DEFS`、`EVENT_CHAIN_DEFS`、`NPC_STORY_DEFS`、`TECH_NODE_DEFS`、`BUILDING_DEFS`、`FACTION_DEFS` 或 `OUTPOST_DEFS`。
- [ ] 所有跨系统变化只使用统一效果操作，并经过 `CommandBus/reducer`。
- [ ] 未引用未登记的资源、岗位、建筑、科技、NPC 或敌人标签。

## 剧情与六视角

- [ ] 有明确的世界因果：黑土、无线电、资源、势力或尸潮目标至少命中一项。
- [ ] 有玩家承诺、可见选择、成本、收益和失败提示。
- [ ] 已写明 NPC 动机、岗位、需求、关系和自治路线。
- [ ] 已写明营地库存、劳动、建筑占位、维护和人口支付。
- [ ] 已写明势力关系、历史记忆、贸易或据点反应（若适用）。
- [ ] 已写明敌人压力、路线、目标或反制来源（若适用）。
- [ ] 已说明对主线、共鸣度、崩溃值、每日总结和最终尸潮的影响。

## 分支与人口

- [ ] 玩家介入路线至少一条；自治路线至少一条。
- [ ] 至少一条保守路线和一条冒险路线。
- [ ] 有 NPC 死亡、失踪、重伤、拒绝合作时的结果。
- [ ] 有人口不足、岗位缺失、材料不足和建筑损坏时的降级路径。
- [ ] 支线过期或玩家跳过后不阻塞主线，并留下可解释的世界结果。
- [ ] 新 NPC 占用固定 roster 名额；没有剧情凭空增员。
- [ ] 英雄的主动技能、营地被动、投票权或可调度节点具有实际系统价值。

## 规则、存档与回放

- [ ] 白天/夜间动作边界通过统一 night guard 校验。
- [ ] `instanceId`、`commandId`、`eventId`、`causationId` 已定义。
- [ ] 重复点击、刷新、加载、回放不会重复扣料或发奖。
- [ ] 保存缺失新字段时使用安全默认值；旧档迁移结果可审计。
- [ ] 每日总结和任务推进从事件账本读取，不读取隐藏临时变量。
- [ ] 固定随机种子和相同输入可重现同一结果。

## 平衡与性能

- [ ] 武器至少有一个克制目标和一个明显弱点；增益未超过设计上限。
- [ ] 科技/建筑成本、劳动、维护和解锁日符合当前尸潮时间线。
- [ ] 夜战不会因新增内容突破实体、动画、寻路和 UI 性能预算。
- [ ] 远处 NPC 使用账本/小队模拟，本地交互才实例化逐人表现。
- [ ] 资产缺失有占位回退；表现替换不改变碰撞锚点和规则语义。

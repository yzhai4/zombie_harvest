# 性能预算与验收

## 目标设备和预算

- 日间目标：中端手机持续 60 FPS，P95 帧时间不高于 16.7 ms。
- 夜间目标：中端手机持续不低于 30 FPS，P95 帧时间不高于 33.3 ms。
- 世界 tick 约 1.2 秒一次；tick 不应同步序列化完整存档。
- 连续移动输入约 50 ms 采样，但不把每个输入脉冲写入事件账本。

## 当前已处理的卡顿源

- `world.advance` 不再触发每个 tick 的同步存档；保留低频 world tick checkpoint，以及切后台、离开页面和关键动作的保存。
- 连续移动和夜间移动使用 ephemeral command，位置仍由 GameState 快照保存，但不洪泛 replay/events/localStorage。
- 夜战 tick 使用 `requestAnimationFrame` 合并地图重绘。
- 状态终端打开时地图只按低频刷新，非当前标签不渲染。

## 验收顺序

1. 先用浏览器 Performance 面板或移动设备录制 30 秒日间和 30 秒夜间。
2. 检查长按移动、打开状态终端、尸潮 tick 是否出现 100 ms 以上长帧。
3. 检查切后台/恢复后只生成一次 catch-up 和 checkpoint。
4. 用旧档恢复、进入下一天、触发一次事件和尸潮，再关闭页面恢复，确认状态一致。

若预算仍不达标，再做地形 DOM 缓存、静态层与角色层拆分；在此之前不迁移引擎。

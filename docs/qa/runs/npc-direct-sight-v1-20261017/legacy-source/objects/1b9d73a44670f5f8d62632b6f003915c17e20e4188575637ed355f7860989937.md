# 03 主线事件链总图

所有主线链均使用稳定 `chainId`，节点效果通过统一 reducer，且有自治、过期和缺岗降级。

## `omen-blacksoil-001` 黑土初兆（day 1–3）

- **触发：** 玩家首次调查农田、旧尸体或异常湿地。
- **玩家路线：** 采样并带回指挥所，`resonancePressure +4`，解锁黑土标签与 `graveyard-008`。
- **保守：** 封存样本，`campCollapse -1`，暂不解锁黑土科技。
- **冒险：** 接通废弃中继线，`resonancePressure +8`，获得脉冲研究钩子。
- **自治：** 唐婶与周岚会把样本移出粮仓；若两人任一缺席，样本暂存工坊。
- **降级：** 无可用岗位时只记录 `blacksoil_seen`，不生成新实体。

## `relay-chain-001` 广播中继链（day 2–7）

现有 `docs/scripts/relay-chain-001.md` 是详细剧本卡，本总图只规定跨链契约：回收核心→交接长官→筹料施工→上线预警。玩家可主动推进、营地可自治修复；广播员死亡或中继损坏时转岗亭/人工哨报。最终影响预警提前量、信号科技、广播员 SAN 和营地合法性。

## `camp-charter-001` 陌生人立约（day 2–10）

- **触发：** 玩家完成一次营地任务或救回可用物资。
- **节点：** 请求帮助→完成岗位任务→接受营地规则→获得 trust。
- **玩家选择：** 支持配给、支援防线或交付稀缺物资；每次选择绑定资源和关系代价。
- **保守：** 只做岗位任务，trust 稳定增加，`campCollapse -2`。
- **冒险：** 用个人战斗成果换授权，trust 增长快但若失败会 `campCollapse +5`。
- **自治：** 林岑根据人口和威胁决定是否授予玩家命令权。
- **降级：** 林岑缺席由贺川主持；两者都缺席时只开放求助，不开放计划会干预。

## `horde-convergence-001` 尸潮汇聚（day 10–16）

- **触发：** 时钟达到 day 10、至少一条预警或黑土线已被记录。
- **节点：** 读取预警→选择目标门→分配英雄/据点守军→最终尸潮结算。
- **保守：** 封锁黑土、保核心和医疗，减少敌人特殊标签。
- **冒险：** 利用共鸣把尸群引向外部势力/空地，成功可降低营地伤害，失败增加聚合体和崩溃值。
- **自治：** 计划会根据票数决定默认门和资源配给；玩家可用 commandPoints 改一个决定。
- **降级：** 无中继用固定窗口；英雄不足用普通 NPC 小队；人口少于 3 直接触发崩溃结算而不生成额外战斗实体。

## 主线不阻塞规则

每条主线至少有一条“无核心 NPC”路径，主线结果永远可以由旧岗亭、人工记录、临时修补或外部势力交易替代，但替代路径更昂贵、更危险或更晚预警。

## 主线缺岗边界

`relay-chain-001` 的核心交接、施工和上线仍依赖其原剧本卡中的林岑、阿梁、周岚、阿默及真实岗位。关键 NPC 缺席时原链暂停或降级，不由陌生替身写入 `relay.stationOnline`；`watchpost-003` 的人工哨报是独立替代预警效果，不能伪造中继完成事实。尸潮链 day10 无条件建实例，缺少预警时读取 `unknown-forecast`。

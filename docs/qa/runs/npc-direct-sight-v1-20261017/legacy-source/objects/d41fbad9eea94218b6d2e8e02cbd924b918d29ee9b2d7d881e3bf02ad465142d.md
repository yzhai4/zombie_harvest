# 科技、建筑、势力与据点模板

科技和建筑必须有材料来源、岗位需求、维护成本、空间占位和世界因果。研究速度来自科研 NPC、计划会、研究台和特殊科技物品；玩家交付物资只能加速既有进程，不能绕过前置。

## 科技节点

```js
{
  id: "signal_t2",
  contentVersion: 1,
  branch: "signal",
  tier: 2,
  name: "中继稳定化",
  prerequisites: ["signal_t1", "relay_core_recovered"],
  cost: { researchPoints: 60, scrap: 18, relayParts: 2 },
  requiredRoles: [{ role: "radio", min: 1 }, { role: "engineer", min: 1 }],
  specialItems: ["calibrated_coil"],
  unlocks: {
    buildings: ["relayTowerT2"],
    weapons: ["pulseAxeMk2"],
    actions: ["jam_screamer"]
  },
  campEffects: [{ type: "resonance_growth", value: -0.08 }],
  fallbackIfRoleMissing: "research_paused",
  hooks: ["onResearchStart", "onResearchComplete"]
}
```

## 建筑定义

```js
{
  id: "relayTowerT2",
  contentVersion: 1,
  category: "signal",
  techRequired: "signal_t2",
  footprint: { w: 2, h: 2 },
  buildCost: { scrap: 40, wood: 20, relayParts: 2 },
  labor: { role: "engineer", slots: 1, workUnits: 35 },
  hp: 180,
  coverage: { radius: 7, key: "signal" },
  inputs: { relayCharge: 1, per: "day" },
  maintenance: { scrap: 2, per: "day" },
  outputs: [{ type: "resonance_forecast", value: 1 }],
  damageStates: ["online", "degraded", "offline", "destroyed"],
  destructionEffects: [
    { op: "adjustMeter", key: "resonancePressure", value: 8 },
    { op: "recordHistory", key: "relay_destroyed" }
  ],
  storyHooks: ["relay-chain-001", "final-harvest-001"]
}
```

建筑必须说明：占位、建造劳动、输入、输出、维护、覆盖范围、耐久、受损阶段、夜间行为、摧毁后果和可修复条件。未登记建筑不得通过剧情直接生成。

## 势力与据点

```js
{
  id: "waterMill",
  contentVersion: 1,
  factionId: "farm_camp",
  captureRequires: ["outpost_clear", "camp_trust>=35"],
  garrison: { min: 1, max: 2, roles: ["guard", "quartermaster"] },
  dailyCost: { food: 1 },
  supplyDistanceReduction: 0.25,
  defenseProfile: "light",
  lossEffects: [
    { op: "adjustMeter", key: "campCollapse", value: 5 },
    { op: "adjustMeter", key: "resonancePressure", value: 3 }
  ],
  hooks: ["onCapture", "onGarrisonChange", "onLost"]
}
```

派驻守军只使用现有人口；人口不足时拒绝派驻并给出原因。玩家占领据点不会自动生成资源、士兵或新 NPC。贸易、外交和据点战斗的结果必须写入 `FACTION_DEFS` 与世界日志。

# 支线事件链模板

支线是可选内容，不得阻塞主线或最终尸潮。请先画出节点顺序，再填写定义。示例字段与现有 `EVENT_DEFS`、`QUEST_DEFS`、`NPC_EVENT_CHAINS` 对齐。

## 注册定义

```js
{
  chainId: "watermill-002",
  contentVersion: 1,
  category: "side",
  priority: 40,
  phase: ["day_4", "day_10"],
  locations: ["waterMill"],
  startConditions: [
    { type: "landmark_exists", id: "waterMill" },
    { type: "camp_trust", min: 25 }
  ],
  nodes: [
    {
      nodeId: "repair_gate",
      once: true,
      choices: [
        {
          id: "repair",
          requirements: ["scrap>=20", "carpenter_alive"],
          effects: [
            { op: "addResource", key: "scrap", value: -20 },
            { op: "adjustMeter", key: "campCollapse", value: -4 },
            { op: "unlockTech", id: "watermill_t2" },
            { op: "recordHistory", key: "watermill_repaired" }
          ],
          next: "secure_output"
        },
        {
          id: "bypass",
          requirements: ["player_tool:wirecutter"],
          effects: [
            { op: "adjustMeter", key: "resonancePressure", value: 3 },
            { op: "scheduleEvent", id: "watermill_breach" }
          ],
          next: "unstable_output"
        }
      ]
    }
  ],
  fallback: {
    ifMissingNpc: "use_existing_role",
    ifInsufficientPopulation: "skip_guard_assignment",
    ifExpired: "watermill_damaged",
    ifSkipped: "ledger_only"
  },
  hooks: ["onDayStart", "onOutpostSecured"],
  optional: true
}
```

## 事件卡必须说明

| 项目 | 填写内容 |
| --- | --- |
| 玩家承诺 | 玩家介入后能改变什么局面？ |
| 时间窗口 | 最早/最晚日、昼夜限制、过期结果 |
| 参与者 | NPC、岗位、势力、敌人目标和最低人数 |
| 节点图 | 触发、选择、结果、后续钩子、结束节点 |
| 资源契约 | 资源扣除、产出、建筑/科技/武器解锁 |
| 仪表影响 | `resonancePressure`、`campCollapse`、士气、关系 |
| 自治结果 | 玩家不介入时营地会做什么，成功或失败如何记账 |
| 降级分支 | NPC 死亡/缺席、人口不足、材料不足、夜间、过期 |
| 主线关系 | 推进、延迟、加速或不影响哪条主线 |
| 存档回放 | instanceId、事件 ID、幂等点和迁移默认值 |

## 设计约束

- 至少一条保守路线和一条冒险路线；每条路线都有可见成本和恢复方式。
- 事件效果只能使用 `addResource`、`adjustMeter`、`modifyRelation`、`unlockTech`、`unlockWeapon`、`scheduleEvent`、`assignJob`、`damageBuilding`、`captureOutpost`、`recordHistory`。
- 玩家选择和自治选择都写入世界日志；每日总结读取日志，而不是读取隐藏临时变量。
- 玩家跳过支线时保留世界因果：例如水磨坊损坏、研究延迟、路线变危险或势力关系恶化。
- 事件链不在夜间直接建造、采集、治疗或改派 NPC；夜间只允许战斗和已提交的准备结果。

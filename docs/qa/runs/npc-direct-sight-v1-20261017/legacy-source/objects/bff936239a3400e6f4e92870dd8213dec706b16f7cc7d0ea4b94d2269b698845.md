# Ideas Backlog

用于记录临时灵感，避免打断当前开发主线。新想法先登记，再按触发条件推进。

## 状态

- Inbox：刚记录，未评估
- Evaluated：已完成影响评估
- Ready：依赖满足，可进入迭代
- Parked：暂缓，不影响当前版本

## 记录模板

### [日期] 标题

- 来源：用户灵感
- 目标：解决什么问题，或增强什么体验
- 影响系统：事件 / 时间 / NPC / 地图 / 存档 / 战斗 / UI

# Scenario C1 independent source acceptance matrix

Status: frozen design before independent candidate execution. The current repository source is 9edb6d3c; the candidate is tested separately. This is controlled source-VM evidence, not a browser, natural-play, or C2 event compiler result.

Inputs: frozen-input-manifest.json preserves ten complete native writers and their original capture categories. Four SAVE18 writers, a pre-snapshot SAVE21 writer, and five later SAVE21 writers cover missing declarations, declared-but-unbound metadata, progressed RNG, exhausted collections, death, remote garrison, settled shortage/cache identity, and natural fresh07 facts. No input receipt is invented. Modified scenes or boot-input variants are explicitly TEST-ONLY.

The IO adapter is the actual scripts/check-report-recovery.mjs factory. DOM/storage/time queues are controlled. The existing bootstrap Canvas render suppression and unrelated rendering instrumentation are retained; read-only helper exports and a pass-through controlled-storage write observer record actual interval counts. Source preparation, validation, Gate, loader, writer, command bus, RNG and production functions run unchanged. Callback execution is explicit and finite. Reports must bind executed runner, adapter, source, pre-boot input transform, original native writers and output artifacts by SHA256.

Old 9edb6d3c source counterexamples established by read-only inspection: no boot-options consumer; fixed default world seed; no initial binding receipt; normalizer/writer drop binding; replay fallback uses seed || default; fresh public start unfreezes/starts the timer before the delayed initial checkpoint. These are pre-C1 gaps, not proof that every old save or gameplay route is broken.

Policy clarification from the parent review: for legacy-unbound, the live snapshot seed and binding.sourceSeed both identify the actual saved worldMeta.seed, including previously legal finite fractions and values outside uint32. The entire old declaration is retained separately in declaredSnapshot even when its claimed seed differs. Actual rngState/replay/inventory are not reset. Fresh and bound records keep the strict uint32 rule. Both missing-declaration and differing-declaration controls already enforce this in the frozen 120-case checker; this annotation changes no assertion.

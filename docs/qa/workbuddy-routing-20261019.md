## 当前调用器和监测合同

调用器仅发送任务所需文件／行段，给出相对路径、行号与 SHA；拒绝越界路径和常见凭据材料。它在空目录运行无工具官方 CLI，禁用 MCP、hooks、项目设置和 transcript 持久化。官方 CLI 仍会产生诊断文件，目录由当前 Windows 用户 ACL 保护；密钥使用当前用户 DPAPI 密文，运行时只注入子进程环境。

常规任务默认 low、请求输出上限 4096 token、有限墙钟截止；复杂推理可显式 high。输出上限和思考预算是请求参数，并非计费保证。[官方环境变量说明](https://www.codebuddy.cn/docs/cli/env-vars)与本机日志均表明必须另核实际行为。CLI 的截断恢复可发生在同一次进程内，回执记录观察到的 provider 请求数量下界，不能把一次 CLI 尝试称为一次 API 请求。

`status --out <目录>` 只读取短回执，不访问模型、凭据或运行时。`pending_receipt` 不证明进程存活；监测子代理仍核具体 session／PID。它每 30–60 秒检查，无变化不回传，只报告完成、失败、实质变化或待决事项，不重发请求、扩预算或自行换模型。主代理只在出现新问题时读取必要局部日志。

Skill 已安装到当前用户发现目录及项目 Skill 目录；仓库保留相同源文件。CI 新增纯离线路由验证，不放入 API 凭据，不自动运行计费探针。

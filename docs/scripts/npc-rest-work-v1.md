# 木匠：低精力恢复与例行工作

状态：候选已接线，验证中。稳定policy ID：`carpenter-rest-work-v1`。不是全职业规划或物理返岗系统；精确状态与保存合同见[ADR](../decisions/ADR-20261018-npc-rest-work-v1.md)。

玩家价值假设：人物说要休整时，实际目标和劳动资格也应改变；玩家能读懂停工原因、恢复条件，并通过已有合法支援介入。该假设尚无真人pilot结果。

## 因果与分支

唯一健康本地木匠本人E<24，且无正式职责／紧迫需求占用时，暂停例行检查、尝试前往本人home，恢复至36后按当时日程安排。原阿梁home=工坊、workZone=东门、小时检查目的地=工坊，均不重写。途中缓恢复保持原+.045，不要求到床、不保证路径畅通或安全。

原支援确认仍2行动体力／15分钟、同目标重核；成功接管取消恢复，免费查看／首谈／合法拒绝不冒充接管。敌情警觉、中继参与、伤病、死亡、据点与岗位变化、战斗／总结／失败让权，不自动续接取消的旧ID。暂停、隐藏、保存／刷新冻结而不凭墙钟补能。

原需求、配给、个人事项与SAN继续。没有新增补能物品、免费指令、强制休整按钮、势力奖励或LLM。新政策数小时的缺岗成本须公开说明，未来调整阈值或速率要单独比较，不能在测试里提速。

当前安排由结构状态派生，在近身菜单、只读查看和名册消费；最近lastReport可被其它事实覆盖，不作为实时安排身份。文案明确“尚未到达／已在常驻区域”“达到36后按原日程”，完成不说“已到工位”。不覆盖当次直接视线报告的独立生命周期。

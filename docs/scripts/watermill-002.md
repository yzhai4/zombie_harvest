## 缺席和失败

材料不足或阿梁死亡/失踪时 repair 锁定，salvage 保持可行；目前没有守卫代修分支。夜间、终局、窗口外拒绝选择。效果失败整批回滚，资源与链节点都不保留半套结果。缺包记录保留但不显示/不执行，待注册后可以重新显示；缺包诊断与启动清单仍属后续任务。

完成事实、appliedEffects、resolvedNodeIds、节点历史和命令 ID 随保存恢复。同一命令与节点不重复领奖；矛盾 active+completed 旧档以 completed 拒绝发放。展示历史裁剪不丢结算事实；选择后回执显示实际差值，双击不会触发另一事件。

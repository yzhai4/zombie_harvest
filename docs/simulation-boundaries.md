# Simulation 与表现层边界

## 可迁移的规则层

`state`、命令总线、事件账本、任务推进、NPC 需求/关系、资源/建筑、昼夜时钟、尸潮结算和存档迁移属于规则层。它们应保持确定性，依靠 `SAVE_VERSION`、checksum 和事件 schema 演进。

连续移动输入是高频表现驱动信号，不写入 replay；玩家位置和世界快照仍会保存。回放边界因此是“命令事件 + 位置快照”，而不是逐帧输入录像。

## 当前 Web 表现层

地图地形和建筑使用 DOM tile，角色使用 canvas，状态信息使用统一状态终端。夜战目前是同图视觉投影加独立 lane 进度模型，尚不是完整地图寻路/碰撞战斗；这是 P1 的明确边界。

## 将来引擎替换的部分

引擎迁移时只替换地图/相机、精灵/动画、输入、音频和资源加载 adapter。不要把单文件 HTML 直接搬进引擎，也不要在规则尚未冻结前重写任务、存档和 NPC 逻辑。

## 长期目标与技术选择

《我是大救星》面向一个会记住、会反应、会形成后果的世界；《尸潮农场》是第一个副本。允许更大地图、更多对象、丰富交互、多个副本与少量具有连续性的特殊角色。现有十人 roster、36×24 地图和早期实验1–2个持久角色是验证范围，不是最终产品上限。引擎、平台、联网、模型供应商和最终角色数量仍未冻结。

核心体验假设是“选择 → 真实后果 → 角色记忆/关系 → 下一次选择”。确定性模拟器拥有事实真相；普通NPC先采用可解释、受预算的规则规划。低频LLM可提出结构化意图或表达评价，必须通过角色知识、能力与成本 Gate；文本不改变物品数值、人口、资源或事件事实。AI OFF 继续使用相同权限、规则及确定性回退。

P0–P6表示证据依赖顺序，不是永久缩小产品，也不等同于旧路线中的P1竖切片或v82–v90版本号。每轮只提交一个可验证行为切片；已有确定性模拟器优先提供反事实基线。只有成本、迁移或规划收益得到证明才考虑 learned World Model，先运行 shadow，不接管事实层。

## 质量评估与工作流调整

每轮依次记录：玩家价值假设 → 当前真实consumer/call path → 剧本与六视角合同 → 最小实现 → 冻结旧版反例和正向回归 → 当前构建浏览器 → QA/manifest → CI与发布状态。已有测试覆盖时直接复用，避免增加只复述实现的断言；只在新缺陷或规则边界产生可重复知识时更新Skill。

| 视角 | 必须回答的合理性问题 |
| --- | --- |
| 玩家 | 能看见什么、能做什么、付什么代价、为何发生、能否改变局面 |
| NPC | 所在地、岗位、需求、知识和动机是否支持行动；拒绝/离营后如何继续 |
| 营地 | 人口、劳动力、粮食、医疗、防线是否守恒，是否重复受益 |
| 势力 | 信息与能力从何而来，承诺和关系为何变化，不空发信任奖励 |
| 敌人 | 压力、生成、索敌、伤害与预警是否有来源、预算及反制 |
| 全局链 | 实例身份、时钟、互斥、延期、fallback、终态和保存是否一致 |

修为无参数click包装和统一只读资格：默认寻找原1.25格内资源；显式ID/对象必须绑定唯一live实例，不可静默换目标。拒绝非白天/暂停、非法或耗尽数量、距离/库存/体力/分钟计划无效及不足编号预算。HUD保原DAY按钮可点击说明拒绝，提交重新核资格。拒绝仍遵循原Bus审计和取消等候语义，不称全状态零写入。

# DAY 随行与中继工程的机会成本

2026-10-18。状态：本地实现与列明回归已通过，开发ref与精确新CI待各自核对；SAVE21／CONTENT3不变。

## 问题与玩家结果

原公开 cover 命令承诺跟随玩家，但 DAY 运动只消费旧 `motionTarget`，日程还会把成员导回岗位。ad762 的受控完整旧 writer 已复现：陈野真实付2体力、推进15分钟并接受 cover 后，玩家换点；他沿原岗位目标移动，距离反而增加。保存订单不等于执行跟随。原反例与失败不重标为通过。

本片让同一个已接受随行命令的 NPC 持续回应玩家换点，同时让带走工程成员产生实际停工代价；不新增剧情、人口、奖励、寻路器或规划平台。

## 决策

纯派生 `dayCoverFollowStatus` 消费现有 `supportRequested === true`、`order === 'cover'`、真实 live 身份和角色订单。所有包含 cover 的现任角色及合法继任者走同一执行链。每个原 DAY 运动步骤重新消费当前玩家位置，沿原碰撞移动，速度仍为每世界分钟0.075格；2.2格圈内待命，玩家换点后继续尝试。圈分类允许1e-9格浮点容差，移动上限仍为原速度与 `distance - 2.2`，不实质扩大跟随范围。

以下优先级只定义本片随行，不提升为全局生命、感官或劳动系统：

- 非 DAY、死亡、据点驻守、身份／位置／生命事实不合法时，不运行 DAY 随行；夜战仍使用原已锁定安排。
- 真实 fleeing／fled 保留原撤退目标；不凭空制造安全点。原精确 commander 实体在核心待交付时仍保接待点例外，交付后重新判断。
- 一致的 injured 且HP至少30可按原速随行；critical 暂停，需要实际治疗。HP30沿现有生命分类。
- 精力低于24或疲劳高于88暂停并消费原休整斜率；饥饿高于78等待原有限配给。E24来自原生理 resting 条件，原行为标签的 E20 与木匠24／36滞回不是同一合同。本片不扩展木匠状态机。
- 正常睡觉／饭点日程、岗位目标和共享警觉不抢随行移动；原需求变化、知识共享、实际感知与射程战斗保留。生理与SAN消费本段事实，不用末端状态倒算整个区间。

## 工程、费用与恢复

中继三岗仍保留唯一实际 holder，另派生 cover 忙碌资格。任何一个工程岗随行，未完成中继的 legacy 筹料／施工及 opt-in stage adapter 都停止新增扣料、materialClock、工时与上线；暂停生理需求或碰撞时同样占用职责。个人例行 workClock 不在随行期间累积。已有投入、余量和合法工时保留。

两条原命令的效果阶段不能合并：`npc.order` 首次支援先设置 support、付2体力并真实推进15分钟，完成门通过后才设新 order；该区间原岗位的合法工程前缀保留。`npc.interact` 默认订单本来就在 advance 前写入，默认 cover 从该赋值边界开始占用职责。中断不退款或回填成功。

近身改为已有 guard／patrol 是释放随行的公开选择；原距离、阶段、身份和自主拒绝仍执行。已有支援换令0追加体力／时间，不再增加 bond、helped 或SAN。不清空 support 标记，不引入取消后重复请求刷收益的入口。解除忙碌后按实际工程条件继续，不补暂停工时，也不承诺瞬移到工地。

已完工历史、奖励、当前站点物理能力及本场锁定遭遇都不因后续随行倒撤。这里仅关闭未完成中继的随行劳动冲突，不声称全营地所有生产、医疗与福利已经统一互斥。

## 保存与呈现

不新增持久 owner 或 SAVE 字段。现有订单、需求、位置与工程事实由正常 writer 保存；Continue 恢复这些事实并在下一次真实 DAY 机会重新派生职责，不重生成地图、补资源或回填跟随历史。旧无支援／无 cover 的记录不自动升级。

复用近身命令、名册与工程面板显示当前随行、暂停原因、费用和释放工程岗的方法。当前状态、上次报告、完工历史及当前物理能力分别表达；既有危险说明不重复堆叠。呈现可见不等于真人已经理解。

| 视角 | 本片因果 |

| 玩家 | 已付费用的命令终于产生位移；带走工程岗有可见机会成本。 |

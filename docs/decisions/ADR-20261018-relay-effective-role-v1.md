# ADR：中继唯一有效岗位

状态：设计已裁决，候选实现／验收中。SAVE21／CONTENT3保持，未部署。问题来源为[继任双岗](../problems/PROB-20261017-effective-role-exclusivity.md)及[公开中继pilot](../qa/relay-pilot-20261018.md)，不把同一实体占两槽说成已发生双倍产出。

玩家需要看清谁承担工程职责、缺什么、为何停工，以及原有进度怎样继续。当前中继是广播员、木匠、后勤官三岗工程；普通岗位、医疗、战斗、计划和指挥所继任界面不在本片统改。

## 决策

1. 三岗按`(actingRole || id)`找到唯一营地本地活人，复用`npcFulfillsRole`。同一live实体／ID只可填一岗，多候选或重复ID不按数组先后任选。保留旧中继伤员准入，不添加healthy、满血、精力或距离门槛。
2. `assignedNpcIds`继续表示岗位槽。当前项目准入要求它是radio／carpenter／quartermaster的完整无重复集合，顺序不限。旧writer／loader保留原数组、历史进度和online，不迁移、不补默认、不回填。空／漏／其它角色／重复的未完成工程在下一次执行时拒绝。这是未来执行收紧，不称所有旧自定义行为不变；项目自定义岗位没有已支持的公开合同。
3. 当次派生绑定纯读，不调用`ensureRelayFacts`或其它规范化写入。default筹料／施工、既有opt-in stage snapshot／提交、本人relay-duty、项目work-pulse和crew共享这一事实，不另存actor映射或新增状态机。
4. 缺岗／歧义／配置无效时，新增中继materialClock、扣料、工程分钟、建站和成功／上线收益前停止；保留此前合法进度和成本。真实世界时间、敌人、需求和配给仍照常，不能断言整个世界静止。
5. 合法三岗配置缺人时，其余唯一绑定者保留原中继待岗职责，不自动释放所有人去恢复；无效／歧义槽不抢任何人的恢复。现有本人支援、警觉、阶段等优先级保持。待岗不得被项目work-pulse写成完成工程劳动。
6. 真实补岗后在下一次原执行机会继续，不补缺岗期间工时、不退款或重付。已online不因以后缺人倒撤事实、奖励或预警；在线维护另立合同。
7. UI分开角色与实际姓名，例如“木匠：周岚（暂代）／后勤官：缺岗”，不固定显示阿梁。缺岗、配置错误和岗位归属不唯一分别解释；保留阶段／进度，避免虚称物理已到岗。动态姓名／报告作为文本呈现。
8. 恢复依已有真实每日upkeep继任；不虚构转岗／召回／取消按钮，关闭N报告不跳日，也不保证一轮继任补完新空缺。长官交付的原核心、距离和四元token Gate不增加施工三岗前置。

动态补测另确认[项目对象替换](../problems/PROB-20261018-relay-project-alias.md)会使旧legacy完工丢失并重复收益。作为同一主链必要修复，规范化改为保持live项目容器身份；不改数值／配方或新建状态机，旧null时间与旧奖励不追溯重算。独立新增legacy完工一次的逻辑回归，不以岗位负控代替它。

## 六视角与验收

| 视角 | 必须保住的事实 |
| --- | --- |
| 玩家 | 同一提示、实际准入与后果一致；能解释等待与已有恢复条件 |
| NPC | 永久身份／需求／继任历史保持，一个当前职责不冒充两岗；待岗与完成分开 |
| 营地 | 原人口、有限来源、已花材料和工时有据，不用补给或假角色使测试成功 |
| 势力 | 不凭原头衔取得新当前能力，不增加外交或虚假合作收益 |
| 敌人 | 原敌、真实伤害和死亡后果保留，source-VM控制时钟不称自然游玩 |
| 全局链 | 真实核心／交付、项目identity、CAS／duplicate、保存／刷新和旧online历史连续 |

先由完整真实命令路径产生的briefed writer定位消费者，再真实死亡／继任复现旧版反例与候选阻断。已有八个stage合同保持；新增岗位逻辑负控覆盖default／opt-in、真实补岗、已投入进度、纯读、等待credit与配置变体，另新增legacy完工一次回归。配置变体明确TEST-ONLY；新增测试不手填项目阶段／材料／角色解决主反例。当前构建实际浏览器核公开crew／停工、真实保存与刷新，source-VM和浏览器不相互代替。

完整自然主线／三日、真人可理解性、全项目有效岗、physical arrival、记忆／规划和引擎迁移继续独立验收。候选通过后才将该片标开发验收，不以设计卡存在、代码diff或旧green作完成证据。

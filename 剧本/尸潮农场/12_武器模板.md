# 武器内容模板

复制本模板新增武器。武器只能通过标签、状态、资源和事件钩子影响世界，不能直接写剧情结局、人口或营地崩溃值。

## 注册定义

```js
{
  id: "weapon_id",                 // 稳定 ID，不复用
  contentVersion: 1,
  displayName: "显示名称",
  family: "axe|blade|spear|ranged|tool|special",
  tags: ["farm_origin", "anti_resonance"],
  damage: { min: 10, max: 16 },
  attackInterval: 1.0,
  staminaCost: 10,
  durability: 100,
  damageTypes: ["slash"],
  penetration: 0,
  knockback: 0.5,
  statusEffects: [],
  activeAbility: null,
  passive: null,
  ammo: null,
  heat: { max: 0, perUse: 0, coolRate: 0 },
  recipe: ["scrap", "wood"],
  techRequired: "defense_t1",
  requiredRole: "carpenter",
  storyHooks: [],
  rarity: "common",
  weakAgainst: ["armored"],
  assetKeys: {
    icon: "weapon_id.icon",
    sprite: "weapon_id.sprite",
    attack: "weapon_id.attack",
    sfx: "weapon_id.attack.sfx"
  }
}
```

## 填写规则

- 至少有一个 `tags` 或 `damageTypes` 克制目标，也必须填写 `weakAgainst`。
- 单把武器的全局增益不超过 20%；强力武器必须绑定稀有材料、特殊事件、耐久/弹药限制或过热代价。
- `family` 决定基础动作和熟练度来源；特殊动作通过 `activeAbility`/`passive` 注册，不能在按钮回调中单独实现。
- 配方只引用现有或已登记资源；`techRequired`、`requiredRole` 和 `storyHooks` 必须有可追溯来源。
- 装备、攻击、命中、维修和夜末分别产生事件钩子；耐久、弹药和热量的扣除必须幂等。
- 伤害类型仅使用统一枚举：`slash`、`blunt`、`pierce`、`fire`、`pulse`。
- 资产加载失败时回退到同 `family` 的占位素材，不影响战斗规则和存档。

## 示例：中继脉冲斧 Mk.2

```js
{
  id: "pulseAxeMk2",
  contentVersion: 1,
  displayName: "中继脉冲斧 Mk.2",
  family: "axe",
  tags: ["pulse", "anti_resonance", "heavy"],
  damage: { min: 34, max: 42 },
  attackInterval: 0.8,
  staminaCost: 18,
  durability: 100,
  damageTypes: ["blunt", "pulse"],
  penetration: 0.2,
  knockback: 1.4,
  statusEffects: ["stun", "resonance_mark"],
  activeAbility: "discharge",
  passive: "resonance_break",
  ammo: { kind: "relay_charge", max: 3, perUse: 1 },
  heat: { max: 0, perUse: 0, coolRate: 0 },
  recipe: ["scrap", "relay_core"],
  techRequired: "signal_t2",
  requiredRole: "engineer",
  storyHooks: ["relay-chain-001"],
  rarity: "prototype",
  weakAgainst: ["swarm", "long_fights"],
  assetKeys: {
    icon: "pulseAxeMk2.icon",
    sprite: "pulseAxeMk2.sprite",
    attack: "pulseAxeMk2.attack",
    sfx: "pulseAxeMk2.attack.sfx"
  }
}
```

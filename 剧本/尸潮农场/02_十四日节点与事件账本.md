# 十四日节点与事件账本

## 1. 账本字段

每个事件实例使用稳定的 chainId、nodeId、instanceId、eventId、contentVersion、phase、triggerSummary、choices、autonomyResult、effects、fallback、causationId、createdDay、resolvedDay 和 status。status 只能是 pending、active、resolved、expired、skipped、degraded。

instanceId 由 chainId、世界种子和首次触发序号组合；同一实例重复 dispatch 只能返回幂等结果。每日总结只读取 resolved 或 degraded 的账本记录。

## 3. 事件节点定义

### day01-arrival-001

触发：day == 1、phase == DAY、camp-farmstead-001 未初始化。玩家选择建立 shelter、仓储或侦察岗；营地自治选择默认 shelter。保守路线消耗较少木材并提高崩溃缓冲；冒险路线多派一名 scavenger，提前获得零件但增加伤病概率。固定 roster 未到齐时只创建岗位空缺记录，不创建居民。

### day03-blacksoil-001

触发：黑土样本可取且农业台未锁定。保守路线封存样本，resonancePressure -2、agri 研究延迟 1 日；冒险路线试种，food 产出 +20% 持续 2 日、resonancePressure +4，并给一个可见的污染警告。缺席时营地默认封存；缺水时自动进入 ledger_only。

### relay-chain-001

严格复用现有四节点：core recovery、core handoff、material/construction、station online。施工选择先保防线或先保中继；上线选择公共频道或静默频道。缺岗、夜间、材料不足、占位冲突和核心丢失都进入现有 resolveFallback，不创建替代 NPC，不重复扣料。

### day08-faction-rumor-001

触发：relayProject 已交付或广播噪声超过阈值。保守路线封锁频道，失去一次交易机会但 noise -2；冒险路线公开频道换取零件 8，noise +5 且 day11 增加一条尸潮侦察路线。无人主持时营地自动封锁频道。

### day11-route-forecast-001

触发：hordeForecast 存在或 day >= 11。玩家可选 north_wall、watermill、relay_side 三条主路线。保守路线选择防守值最高路线；冒险路线选择可获得补给但覆盖薄弱的路线。缺席时按 defense domain 最大值选择，并记录自治原因。

### day13-final-prep-001

触发：day == 13 下午、所有可选支线已结算或过期。玩家提交 food、water、ammo、repair kits、守军和诱饵。提交后不允许重新分配；人口不足或岗位缺失按降级表压缩准备值，不凭空补充资源。

### day14-final-harvest-001

触发：day == 14、finalPrepCommit == true。四阶段敌潮由 final-harvest-001 账本生成；每阶段结束只写夜战结果，不能触发新的白天选择。结算后进入 summary-day-001。

## 4. 自治、缺席与降级账本

营地自治使用 autonomy.effects，不能伪装为玩家 choice。缺席分为 absent（未到场）、incapacitated（重伤/恐慌）、dead（死亡）和occupied（岗位已被占用）。每种状态都写 fallbackReason。

| 条件 | 默认行动 | 数值后果 |
| --- | --- | --- |
| 玩家未处理 1 个白天节点 | 先保人口和防线 | 目标产出 -10%，压力 -1 |
| 玩家未处理 2 个节点 | 保守计划投票 | 稀有材料不投入，科技延迟 1 日 |
| 玩家缺席整日 | 岗位按既有优先级运行 | 额外疲劳 +2，事件仍可完成 |
| 关键 NPC 缺席 | 使用现有同角色岗位，若无则暂停 | 不生成替代人口，生产降为 0.6 倍 |
| 材料不足 | 保留已交付事实，进入补料 | 进度不倒退，下一日可重试 |
| 夜间尝试白天命令 | 拒绝命令 | 状态、资源和日志不发生部分写入 |
| 事件过期/跳过 | ledger_only 或 damage | 主线继续，下一总结说明后果 |

## 5. 每日总结输出

summary-day-001 必须展示：完成/跳过事件、玩家与自治选择、消耗/产出、岗位工时、NPC 关系变化、建筑损伤、resonancePressure、campCollapse、hordeForecast、下一日预警和可恢复入口。总结不能读取临时 UI 状态。

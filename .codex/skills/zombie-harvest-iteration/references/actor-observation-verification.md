# 角色观察验证边界

涉及NPC自述、角色知识或模型表达适配时使用。完整目标见`docs/decisions/ADR-20261017-actor-observation-v1.md`；首谈self合同见`docs/decisions/ADR-20261017-npc-self-observation-v1.md`，状态以当前QA为准。

- 从实际公共Gate返回的同一live目标绑定speaker；父命令actor可能是玩家，不等于发言NPC。默认interact Gate受talkOpen影响，在改变UI标志后重跑会把免费首谈误判成付费支援；只读子步骤不能增加原行动的成本或健康工作门槛。
- 保存validator通过不保证成对事实自洽。例如旧lifeState与HP可能冲突；新观察依实际规则检查，冲突保守unknown，不调用normalize或悄悄改旧世界。相关全局问题保持独立，不能因自述降级而宣布全局已修。
- 缺失或非法信任不伪造0，也不据此编造不信任心理。授权知识与披露交集分开；没有来源的需求不填正常，近距离、可交谈、高信任都不等于看见其它对象。
- 观察者与听众的知识分别评估：附近NPC可把本人确实感知且允许披露的敌情告诉尚未知情的玩家。不能仅因地图迷雾／渲染差异就要求玩家已看见全部目标，从而取消侦察价值；也不能借口NPC口报读取它未感知的全图实体、精确HP或意图。报告不自动改变地图发现事实。
- 私有capture/project可以纯读，整个公开动作仍有UI、命令、账本和checkpoint。不要调用会默认化社会域的摘要函数作纯捕获；也不调用感知更新来制造新知识。
- 哈希绑定不是世界授权或保密证明，低熵隐藏字段的hash也可能泄露信息。未来不可信适配只取已披露DTO，不给内部captured快照、宽知识对象、原始subject或可绕过披露的函数。
- 自述须在实际UI完整可读，核换行、裁剪、viewport和停留时间；DOM文本完整不证明玩家看得到。普通提示恢复原行为，未知界面提示不归因成NPC已确认的事实。
- 合法输入还要走实际继续、renderer、pagehide writer与reload；只验证输入不保证旧consumer不会写出非法状态。负信任的晋升进度须在总值上守0..100，不能改信任来源、取消其抑制效果或放宽存档validator。已知满进度事件去重另立问题，不混入边界修复。
- 继续旧档可能没有立即重写storage；以真实公开启动状态和原生writer建立基线，不把“字节必须立即变化”当游戏合同。保存只含NPC ID时，公开名称须对固定模板／捕获清单核对，不假定writer存了name。viewport改变后按实际CSS过渡等待布局稳定，再断言相同可见性标准。

按明确的支持topic验收。self不需要对自己调用canPerceive，也不证明直接视野、contacts或共享信息已获授权。原Gate、支援成本、真实中断和旧writer事实分别保留，源码／实际浏览器／自然玩法各自报告。

冻结大型仓库可只复制实际依赖，但应沿checker的manifest和输入映射收集完整闭包。跳过顶层历史runs时不能连带跳过`scripts/fixtures/.../frozen/docs/qa/runs`；静态内容校验还依赖L0和Skill文档。缺输入或冻结时的并发修改属于方法失败，保留原件，不记成游戏缺陷或通过。

# 公开试玩的行动与采样

用于实际键鼠／触控的短路线、成对工程pilot与自然路线；不把以下方法验收代替真人理解或平衡实验。

- 按实际父业务命令、支付及真实中断核主要动作。地图点击、快捷键或名为“选择／查看”的操作可能直接提交；终态用账本校正，自动`world.advance`子命令不另算一个玩家决策。预设spec标签不能证明免费或没有风险。
- 未暂停的世界在读图、RPC、截图和思考期间继续运行。行动前重新读即时HP／危险；批量导航逐步核位置和停止条件，未位移不盲重复。取证尽量在停止并清理后完成；不在危险现场长停等报告，也不为完成而暂停或改rate。显式wait／轮询窗口与整个观察取证段的起止差分列；协议若限制整段世界分钟，按该段累计差执行停止，不能用各wait窗口之和代替。累计账本仍计入全部实际世界费用。
- HP变化只在同一实际活动阶段比较。启动／重载遮罩默认值与Continue恢复值的显示切换不计伤害；恢复后的活动数值与真实伤害收据分别留证。既有误标用companion说明并保原件，不放宽HP阈值或改游戏成本。
- 时间行动按实际入口成本预检危险；一次先前的安全判定会随采样滞后失效。安全veto只阻止行动，不提供隐藏目标／最优路线；若读完整writer，单列权限与用途。
- 实时公开UI、只读权威采样与最后耐久writer分别列世界时间／采样时刻；同一capture按顺序取样并非原子现场，截图可能晚于JSON，累计费用取最新实际可证水位并保未知终态。保存字节未更新不证明实时世界没变。等待新tick进入正常writer时，按真实checkpoint周期、去抖及reload是否重置计数安排整个方法窗口；短于所需周期的超时不能诊断为存档失败。死亡画面不等于死亡已写盘；未等正常checkpoint或未reload就保留未覆盖。
- 声称同raw／完整payload恢复时，先保reload前正常writer，再只读捕获BootRecovery实际选中的raw／payload、checksum、来源及日历／seq，按声明范围比较。同水位、同效果或新tick不能证明同raw；pagehide可能另写同水位checkpoint。缺selected原件时仅报告已验水位／效果／新tick，不推定字节相同或唯一差异，原报告保持不变。
- 运动未位移先核会话、模态、公开碰撞与风险；没有输入采样不能宣称焦点已排除。依据原源码／存档的静态几何只是解释，不冒充逐帧重放或安全路线证明。
- 自动探索公开地图时，区分已见地块、已知通路与暂未连接的地标；先在当前可达的已观察区域选择前沿，不能由一个可见目标无路径就推定游戏不可达。保留当前短路径目标至到达、碰撞或相关新观察，并记录目标的公开来源及换路原因；过去公开观察可作记忆，隐藏世界坐标不补路线。建筑泛称或外观猜测只产生有限探查候选，实际交互入口出现后才确认能力。
- 原始失败报告、执行方法及字节不改。方法误计用独立companion更正并指明证据；新方法另立执行身份。相同seed而不同阅读／动作节拍仍会改变暴露和RNG，单操作者两条路线不能承担食物或其它因素的因果结论。
- 受控续跑使用实际正常writer，记录它与停止时live的回退量，并把已观察世界分钟、活动wall、导航、UI和经真实收据校正的业务成本带入实际helper限制；恢复不能重给原预算，也不能继承已知漏计或中途快照。旧公开地图可作带时刻记忆，新boot画面仍先取得；不能用较晚现场代称较早恢复位置。此类续跑不计single-fresh或单次从头自然路线。
- 修改launcher／driver参数绑定后，syntax不能证明传入了正确的Chrome、输入或预算；核实际调用表达式与冻结启动参数。预检修正前的方法原件保留，方法控制不计浏览器或游戏执行。

反例见[中继工程pilot](../../../../docs/qa/relay-pilot-20261018.md)。完整目标继续是可读、可干预的实际主线与玩家体验，不能靠追加trace或检查数量取代。

实际画面可提供DOM／context未表达的方向；无方向的自动驾驶停止不是玩家观察或产品可达性结论。换视觉方法时另冻身份，先核本次恢复后新图与SHA；较晚live图不能当作较早正常writer恢复现场。观察／预算协议服务于具体比较，不把一次短probe变成全部玩法的无限前置。

实际公开attack出现也要区分提交半径，未按F不能说已失败。例见[公开反馈QA](../../../../docs/qa/relay-public-feedback-v1-20261018.md)。

新probe先区分原全局累计上限与已结束局部probe：可以另立执行身份和有限局部目标，仍扣已花全局费用、实际回退和未知尾段，不重开原失败、重置全局预算或把跨构建结果当原比较通过。控制方法与玩家分支／主线结果分别验收；为正常写档观察付出的世界时间同样可能触发真实有限工程，记录发生阶段，不能归因给并未执行的业务。

公开导航同时核地图的连通性、网格route对连续目标的可表达性、末端移动精度与实际交互范围；只验欧氏距离余量不足以证明route能表达目标。空route先定位方法条件，实际没有发键就不能称道路阻挡；修正后仍以真实输入、位移和context确认。案例见[公开续跑QA](../../../../docs/qa/public-relay-prefix-a05-a06-20261018.md)。
